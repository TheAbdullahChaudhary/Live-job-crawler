# OpsBoard Sites App

This directory contains the Sites deployment for the live DevOps, SRE, and cloud engineering job board.

## Features

- Filter-driven live searches by role and location
- DevOps, Site Reliability Engineer, and Cloud Engineer role filters
- United States, Australia, Europe, and Middle East location options
- Live provider health, saved roles, responsive job cards, and fallback handling

## Run locally

```bash
pnpm install
pnpm dev
```

The original FastAPI crawler remains in the repository root.
